- 기능마다 router → service → repository (SQL은 repository에만).
- 회원: meerkit `get_current_user`·`require_role`. 말모아 `security.py`·`accounts.py`·`users` 모델·토큰 검증(11/03)은 없앤다.
- `user_id`는 `INTEGER → users.id ON DELETE CASCADE`.
- 마이그레이션: meerkit 기록 위에 **새 마이그레이션 1개**로 말모아 표 8개 (jobs, people, events, event_reminders, llm_settings, llm_usage, llm_usage_limits, recorder_beats). 겹치는 표 이름은 `users` 하나뿐 (확인함). 말모아 기존 마이그레이션 11개는 가져오지 않는다.
- 서버 시작 때 할 일(작업자·알람 검사·운영 설정 검사)은 `APIRouter(lifespan=…)`로 붙인다. FastAPI 0.143.3이 라우터 lifespan을 앱에 합쳐 줌을 확인함 → `main.py` 수정 없음.
- 말모아 설정은 `features/shared/config.py`가 같은 `backend/.env`를 읽는다.
- 라이브러리: 서버용(anthropic, cryptography, fpdf2, python-docx, imageio-ffmpeg 등)과 **Mac 작업자 전용 그룹**(openai-whisper, numpy, macOS에서만 pyobjc). Docker 이미지에는 Whisper가 들어가지 않는다. pgserver는 쓰지 않는다.
- 지금 합치지 않는 것: 말모아 `file_store` ↔ meerkit `app/storage`, 말모아 AI 호출 ↔ meerkit `app/llm`. 각자 그대로 두고 나중에 결정.
- 테스트: `tests/features/` 아래. meerkit conftest(테스트 DB `_test`, 테스트마다 롤백)는 그대로, 회원·토큰 준비는 하위 conftest. local·s3(moto) 두 모드.

## 단계 5 뒤 화면 다듬기 (2026-11-04)

사용자 시안 두 장(로그인, 내 정보)을 따라 고쳤다. **모양은 시안, 내용은 실제로 동작하는 것만** (CLAUDE.md 5절 "실제 기능과 연결되지 않은 버튼은 만들지 않는다").

- **로그인** (`components/malmoa/login-screen.tsx`): 잠긴 바탕화면(아이콘·위 막대·작업 표시줄, `inert` 라 누를 수 없음) 위에 98 "말모아 OS 로그인 v1.0" 대화상자. SECURE 자물쇠 머리, 라벨 왼쪽 입력칸(사용자 아이디(U)·암호(P)), 단추 확인(O)·아이디 찾기(I)·암호 찾기(F)·회원가입(N) — 밑줄 글자는 `accessKey`. 로그인·잠금은 meerkit `useLogin`·`useLoginLockout` 그대로 쓰고 폼만 새로 그림. 가입은 meerkit `AuthPanel`(약관·이메일 인증)을 같은 창 안에. 창 아래 상태 막대는 `GET /api/health` 로 서버 연결 표시.

- **둥둥 움직임**: 두 대화상자가 6초 주기로 3px 오르내린다 (`malmoa.css` `.malmoa-float`). 컴퓨터의 "동작 줄이기"가 켜져 있으면 멈춘다(녹음 로고 막대도 같이).
- **끌어 옮기기** (`components/malmoa/use-drag-move.ts`): 두 대화상자는 제목 막대를 잡고 끌어 옮긴다(마우스·터치). 끄는 동안은 둥둥 움직임이 멈추고 놓으면 다시 움직인다. 창이 담긴 영역(내 정보는 아이콘 줄·위 막대·작업 표시줄 안쪽) 밖으로 다 나가지 않게 제목 막대 일부(가로 120px·세로 32px)는 늘 남긴다. 제목 막대의 ✕ 단추를 누를 때는 끌지 않는다. 화면을 옮기면 처음 자리로.
  - 함정: Tailwind `paused`(tw-animate-css)는 `@layer utilities` 안이라 층 밖의 `.malmoa-float { animation: … }` 에 져서 멈추지 않았다 → `malmoa.css`에 `.malmoa-float.paused`. 끌기 훅이 ref 를 객체로 돌려주면 React 컴파일러 lint(`react-hooks/refs`)가 막아서 `data-drag-root` 표시로 창을 찾는다.
