### 단계 2. 데이터 이전 (로컬)

- 스크립트 `preview → backup → apply` (legacy `storage_migrate.py`와 같은 방식). 말모아 DB(pgserver `malmoa`) → 이 프로젝트 DB(Docker 5433 `starter`). 회원은 legacy `users.meerkit_user_id`로 잇는다 — legacy가 이미 같은 meerkit DB의 회원 번호를 쓰고 있어 번호가 그대로 맞는다.
