## 2. 비밀 값이 있는 곳

**Git·채팅·화면에 내지 않는다.** Mac 파일은 모두 홈 폴더, 권한 600.

| 파일 / 위치 | 내용 | 쓰는 곳 |
|---|---|---|
| `~/.malmoa-prod.env` | 운영 `DATABASE_URL`, Supabase Storage S3 열쇠 | 이 Mac 에서 운영 DB·저장소 확인·마이그레이션 |
| `~/.malmoa-render.env` | Render 에 넣은 **운영 설정 32줄 원본** (위 값 + JWT·SECRET_KEY·메일·작업자 해시 등) | Render Environment 와 같게 유지 |
| `~/.malmoa-worker.env` | Mac 작업자 열쇠 (`MALMOA_API_URL`은 아직 빈칸) | 단계 8 Mac 작업자 |
| Render › malmoa-api › Environment | 위 32줄 | 운영 서버 |
| Vercel › malmoa › Settings › Environment Variables | `API_PROXY_TARGET` (Production 만, 비밀 아님) | 화면 빌드 |
| `backend/.env` (Git 제외) | **개발용**. `SEED_ADMIN_PASSWORD` = 개발·운영 admin 첫 비밀번호 | 이 Mac |

- `SECRET_KEY`는 Mac 과 운영이 같다(설정 화면에서 넣은 AI 키 암호화용 — 나중에 데이터를 옮겨도 풀리게). `JWT_SECRET_KEY`는 운영 따로.
- Render 에 값 넣는 법: 터미널에서 `grep '^KEY=' ~/.malmoa-render.env | cut -d= -f2- | tr -d '\n' | pbcopy` → Render Value 칸에 ⌘V → `pbcopy < /dev/null`(클립보드 비우기).

## 3. 자주 하는 일

### 설정 바꾸기 (Render)
`dashboard.render.com` → My project → **malmoa-api** → **Environment** → **Edit** → 값 바꾸기 → **Save Changes → Save and deploy** (1~3분 뒤 Live). 바꾼 값은 `~/.malmoa-render.env`에도 같게.

### 화면 주소가 바뀔 때 (예: `malmoa.meerkit.dev` 연결)
1. Render `CORS_ORIGINS`, `FRONTEND_BASE_URL` = 새 주소 (끝 `/` 없이. CORS 는 쉼표로 여러 개 가능, FRONTEND 는 하나 — 메일 링크 주소)
2. Vercel `NEXT_PUBLIC_SITE_URL` = 새 주소 (Production) → Deployments › ⋯ › Redeploy
3. 확인: `curl -X OPTIONS https://malmoa-api.onrender.com/api/health -H "Origin: <새 주소>" -H "Access-Control-Request-Method: GET"` → `access-control-allow-origin`

`malmoa.meerkit.dev` 는 Vercel Domains 에 추가해 둠(Verification Required). meerkit.dev 관리자가 Porkbun 에 **CNAME `malmoa` → Vercel 이 보여 준 값**, **TXT `_vercel` → `vc-domain-verify=malmoa.meerkit.dev,…`** 를 넣으면 된다(기존 `_vercel` TXT 3줄은 지우지 않고 추가). 값은 Vercel 화면의 복사 단추로.

### 열쇠 바꾸기
| 열쇠 | 바꿀 때 | 순서 |
|---|---|---|
| Brevo SMTP key | 메일이 안 옴, **90일 동안 메일 0통이면 만료**, 샜다고 의심 | Brevo › Settings › SMTP & API › Generate SMTP key → `save_brevo_smtp.py`(2525 로그인 확인 후 저장) → Render `MAIL_SMTP_PASSWORD` → 옛 key 삭제 |
| Mac 작업자 열쇠 | 샜다고 의심 (이 열쇠로 **모든 회원의 녹음 원본**을 받을 수 있다) | `uv run python scripts/malmoa_worker.py new-token` → 해시는 Render `MALMOA_WORKER_TOKEN_HASH`, 열쇠는 `~/.malmoa-worker.env` |
| Supabase DB 비밀번호 | 샜다고 의심 | Mac 에서 만들어 파일에 쓰고 클립보드로 Supabase Reset 에 붙여넣기(화면에서 만든 값을 복사하면 두 번 실패했음) → Render `DATABASE_URL`, GitHub `PROD_DATABASE_URL` |
| Storage S3 열쇠 | 샜다고 의심 | Supabase › Storage › S3 › New access key → Render `STORAGE_S3_*` → 옛 열쇠 삭제 |
| `JWT_SECRET_KEY` | 샜다고 의심 | 새 값 → Render. **모든 로그인이 풀린다** |
| `SECRET_KEY` | 되도록 안 바꿈 | 바꾸면 설정 화면의 AI 키를 다시 넣어야 함 |

### 운영 DB 를 바꾸기 전 백업
```bash
F=~/Desktop/legacy/Malmoa/backups/malmoa-PROD-<무엇>-$(date +%Y%m%d-%H%M).dump; umask 077
URL=$(grep '^DATABASE_URL=' ~/.malmoa-prod.env | cut -d= -f2- | sed 's#postgresql+psycopg://#postgresql://#')
docker run --rm -e U="$URL" postgres:17 sh -c 'pg_dump "$U" -Fc --no-owner --schema=public' > "$F"
```
(Docker 는 명령 보호막 밖에서. 순서: 미리보기 → 백업 → 승인 → 실행 → 확인)
