# 01. 기획

## 서비스

- **이름:** 말모아 (Malmoa)
- **부제:** 녹음은 글로, 회의는 기록으로.
- **한 줄 정의:** 회의 녹음을 텍스트로 바꾸고, AI가 논의·결정·할 일을 정리한 회의록을 만들어 주는 개인용 웹 서비스.

## 사용자와 사용 상황

| 항목 | 내용 |
|---|---|
| 사용자 | 1명 (Mac 소유자). 다중 사용자 서비스가 아님 |
| 장소 | 교실·회의실. 여러 사람이 말하는 대화를 **Mac 내장 마이크(또는 외장 마이크) 하나**로 녹음 |

| 회의 중 | 녹음하면서 이전 회의 결과를 열어 보고, 화이트보드를 사진으로 찍어 올림 |
| 회의 후 | 텍스트를 확인·복사하거나 AI 회의록을 만들어 편집하고 MD/TXT로 내려받음 |

## 핵심 원칙 (바꾸지 말 것)

1. **음성 인식은 Mac 로컬에서.** 음성 파일은 외부로 보내지 않는다. Whisper(음성), Apple Vision(사진 글자 인식) 모두 로컬.
2. **AI API에는 텍스트만 보낸다.** 회의록 작성에 필요한 변환 텍스트만 전송하고, 이 사실을 화면에서 안내한다.
3. **유료 API 호출 최소화.** 긴 원문은 구간으로 나누되 필요 이상 호출하지 않고, 작업마다 사용 토큰을 기록한다. API 없이 쓰는 경로(복사)를 항상 남긴다.
4. **처음부터 다시 하지 않는다.** 변환·회의록 모두 구간 단위로 저장하고, 실패하거나 서버가 꺼져도 완료된 구간부터 이어서 처리한다.
5. **지어내지 않는다.** 원문에 없는 담당자·일정·결정은 만들지 않고 `확인 필요`로 표시한다.
6. **민감 정보는 로컬에만.** API 키·DB 비밀번호·암호화 열쇠(`SECRET_KEY`)는 `backend/.env`에만. 녹음·원문·개인정보는 Git에 올리지 않는다.
7. **실제 기능과 연결되지 않은 버튼은 만들지 않는다.**

## 범위

### 하는 것
- 브라우저 직접 녹음(10초마다 저장·복구), 음성 파일 업로드, 화이트보드 사진 업로드
- 한국어 음성 → 텍스트 (긴 녹음 분할·재개)
- 사진 → 텍스트 (Apple Vision, 한국어+영어)
- AI 회의록 8개 항목 생성, 화면 편집·저장, MD/TXT 다운로드
- 회의 참석자 등록(명단에서 고르기·직접 추가)과 표시
- 작업 삭제 (원본·원문·회의록·임시 파일·기록 한 번에, 확인 창)
- 원문 보기·복사 3종(텍스트만 / 시간 포함 / 회의록 요청문과 함께)
- 작업 상태 표시와 목록(검색·필터)

### 하지 않는 것 (현재)
- 화자 분리(누가 말했는지 — 참석자 등록과는 별개), 실시간 자막
- 클라우드 배포, 다중 사용자 운영 (자체 로그인은 2026-11-02에 지움. npm 로그인 라이브러리로 연결 예정)
- 유료 서비스 자동 가입·결제
