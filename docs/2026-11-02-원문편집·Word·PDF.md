## 1. 원문 직접 편집

### 화면 (`job-result.tsx` 왼쪽 원문 창)

- 머리줄 **✏️ 원문 편집** → 문장마다 입력칸. 시간 버튼은 그대로 있어 **들으면서 고칠 수 있다**.
- 고친 문장에 `고침`, 비운 문장에 `지움` 표시. 아래에 "N개 문장 고침" · 취소 · **💾 원문 저장**.
- 저장하면 머리줄에 `직접 수정됨` · `✓ 저장됨`.
- 변환 중·회의록 작성 중에는 편집 단추가 꺼진다.
- 문장 줄은 `memo` 부품(`EditRow`): 2시간 녹음은 문장이 수천 개라 한 글자 칠 때 고친 줄만 다시 그린다.

### 서버 `PUT /api/jobs/{id}/transcript`

- 요청 `{texts: string[]}` — 지금 원문의 문장 순서·개수 그대로, 문장마다 글자만.
- 시간(start·end)·확신도는 서버 값을 유지. 줄바꿈·연속 공백은 한 칸으로, **빈 문장은 지운다**.
- 원문 `.json`(+ `editedAt`)과 `.txt`(음성은 `[시:분:초]`, 사진은 글만)를 다시 쓴다. 쓰는 코드는 `transcriber.write_transcript()` 하나로 모았다(변환·사진 읽기와 같은 형식).
- 실패한 회의록 작성의 구간 메모(`work/{id}_minutes`)는 고치기 전 원문으로 만든 것이라 지운다.
- 409: 변환·회의록 작성 중, 또는 문장 개수가 다름(그사이 원문이 바뀜). 400: 문장 하나 5,000자 초과.
- `GET /transcript` 응답에 `edited` 추가.

### 고친 원문이 쓰이는 곳

텍스트만 복사 · 시간 포함 복사 · **AI 프롬프트 포함 복사** · 원문 TXT 받기 · 다음 **AI 회의록 만들기/새로 만들기**.
**이미 만든 회의록은 바뀌지 않는다** (편집 중 안내문에 적어 둠).

## 2. 회의록 Word·PDF

- `GET /api/jobs/{id}/download?format=docx|pdf` (기존 md·txt 그대로). 파일 이름 `{원본이름}_회의록.docx/.pdf`.
- `backend/app/services/export.py`: 말모아 회의록 형식(`#`·`##`·`###`·`-`·`**굵게**`·`---`·`*기울임 한 줄*`)만 읽는 작은 변환기. 그 밖의 줄은 일반 문단으로 넣어 글자를 빠뜨리지 않는다.
  - Word: `python-docx`. 제목=Title, `##`=제목1, `###`=제목2, 목록=글머리표. 글꼴 Apple SD Gothic Neo (Windows Word에선 맑은 고딕 등으로 대신 보임).
  - PDF: `fpdf2`, A4. Mac 기본 글꼴 `/System/Library/Fonts/AppleSDGothicNeo.ttc`(일반 0번·굵게 6번)를 넣는다. 없으면 AppleGothic, 둘 다 없으면 500 "PDF에 쓸 한글 글꼴을 찾지 못했습니다".
- 화면: 오른쪽 회의록 아래 **📝 Word 받기 · 📕 PDF 받기 · 📤 Markdown · 💾 TXT** (편집 중에는 꺼짐), 메뉴 `내보내기`에도 4가지.
- 새 라이브러리 2개: `python-docx`, `fpdf2` (+ 딸림 lxml·pillow·fonttools).

## 3. AI 프롬프트 포함 복사: 설명 미리 보기 (추가 요청)

요청: "AI 프롬프트 포함 복사 버튼을 누르면 'Whisper 변환 원문 뷰어' 붙이기 전 설명 내용을 볼 수 있게"

- 버튼을 누르면 바로 복사하지 않고 대화상자(`prompt-copy-dialog.tsx`)를 연다.
  - **① 원문 앞에 붙는 설명(요청문)** 전체를 보여 주고 **고칠 수 있다**. 고치면 '기본 설명으로 되돌리기'가 나온다. 고친 설명은 그 화면을 떠날 때까지 유지(저장하지 않음).
  - **② 그 뒤에 붙는 Whisper 변환 원문**(사진이면 '사진에서 읽은 글'): 처음 4줄 + "… 이하 N줄", 총 줄 수·글자 수.
  - 복사만 하므로 말모아에서 전송·비용 없음, 붙여 넣는 서비스로는 원문이 간다는 안내.
  - **📋 설명 + 원문 복사** → ①(고친 내용) + 빈 줄 + ② 를 클립보드로.
- `lib/minutesPrompt.ts`를 `buildPromptInstructions()`(설명) · `transcriptBlock()`(원문) · `joinPrompt()`로 나눔. `buildMinutesPrompt()` 결과는 예전과 **글자 하나까지 같음**(음성/사진 × 참석자 있음/없음 4가지 비교).
- 시험(5182 → 8003): 대화상자 열림 → 설명 첫 줄·원문 미리보기 확인 → 설명 고침 → 되돌리기 보임 → 복사 → **클립보드 내용이 '고친 설명 + 원문'**과 같음 → 되돌리기 → 390px에서 가로 넘침 없음. 브라우저 오류 0.
