## 한 문단 요약

말모아는 **Mac 한 대에서 혼자 쓰는 회의 기록 웹앱**입니다. 브라우저로 회의를 녹음하거나 음성 파일·화이트보드 사진을 올리면,
Mac에서 **로컬 Whisper**(음성)·**Apple Vision**(사진)으로 텍스트를 만들고, 원하면 **OpenAI 호환 API**로 회의록을 씁니다.
API 키가 없어도 "회의록 요청문과 함께 복사"로 텍스트를 ChatGPT·Claude에 직접 붙여 넣어 쓸 수 있습니다.
프런트엔드 Next.js 16(포트 3001), 백엔드 FastAPI(8010), PostgreSQL 16(5432, 로컬 pgserver). `./start.sh` 하나로 전부 켭니다.
