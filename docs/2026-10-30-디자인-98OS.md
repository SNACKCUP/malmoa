## 4. 화면

### 말모아 녹음기 `/` (`recorder-panel.tsx`) — 사용자 요청으로 시안에서 배치를 여러 번 바꿈

```
[녹음 중일 때만: 백그라운드 녹음 안내 띠]
┌ 창: 말모아 - 사운드 레코더 v1.0 [홈 › 녹음기] - [상태] ──────────────────┐
│ 파형(오실로스코프, 실제 마이크 값)          │ 녹음 시간 00:00:00.00 · LED 레벨 · 안내 │
│ [녹음 시작][일시정지][재개][녹음 종료] (같은 크기, 파형 폭) │ [🚀 텍스트로 변환]          │
│ 녹음 결과: 듣기 · 파일 저장 · 초기화                   │ 자동 저장 상태(CHUNK)        │
│ 1. 소스 파일 업로드 및 카메라 촬영                     │ 녹음 및 회의 메타데이터 환경설정 │
│ 텍스트 변환 진행 상황 + 결과 문서                     │   (마이크·회의실 모드·참석자)  │
│ 도움말 3칸                                      │ 작은 달력(다음 일정·날짜별 일정) │
└ 상태 표시줄: 상태 · 샘플레이트 · 브라우저 보관 크기 ──────────────────────┘
```

- **단축키** Alt(Option)+R 시작 · P 일시정지 · C 재개 · S 종료
- **파형**: `useRecorder`가 분석기(`analyser`)와 `sampleRate`를 내보내고, 캔버스가 매 프레임 그린다
- **텍스트 변환 진행 상황** (`transcribe-progress.tsx`): 녹음을 보내거나 파일을 올리면 4단계(서버로 보내기 → 변환 대기 → 음성→텍스트 % → 완료) + LED 막대 + 경과 시간. 끝나면 **결과 문서를 그 자리에서**(변환 원문 / AI 회의록 탭, 텍스트 복사), 실패하면 다시 시도. 작업 ID를 `sessionStorage`(`malmoa-recorder-sent-job`)에 두어 화면을 옮겨도 이어 보임
- **소스 파일 업로드**: 파일 변환기와 같은 부품(`SourceUpload`, `compact`). 올리면 위 진행 상황으로 이어짐
- **작은 달력** (`mini-calendar.tsx`): 다음 일정 알림, 월 이동·오늘, 일정 있는 날 빨간 점, 날짜별 일정(누르면 일정 창, ✕ 삭제), 일정 추가, 큰 달력 열기. 예전 홈 위쪽 "오늘 일정" 줄은 이 안으로 옮기고 지움

### 파일 업로드 & 변환 `/upload` (새 경로, `upload-panel.tsx`)

1. 소스 파일 업로드 및 카메라 촬영(끌어다 놓기·찾아보기·화이트보드 사진) + 포맷 적합성 검사
2. 대기 큐 및 작업 현황판(최근 8개: 진행 막대·상태·변환 시작/결과 보기/다시 시도/삭제)
3. 로컬 엔진 상태(Whisper 모델·ffmpeg·AI 연결, 처리 중 작업 진행 LED)
4. 사진 OCR 미리보기(가장 최근 사진, 확신 낮은 줄 `[확인 필요]`)
- 아래: "변환 완료 후 회의록 뷰어로 즉시 이동"(방금 올린 파일), **대기 항목 전체 변환 시작(Alt+G)**

### 회의 작업 목록 `/jobs` (`job-list.tsx`)

검색(파일명·참석자) · 기간(전체/오늘/7일/30일) · 정렬(최신/오래된/이름) · 새로고침 · 상태 탭(개수 포함) · 체크 선택 → **선택 항목 일괄 변환 · 실패 항목 다시 시도 · 선택 삭제(확인 창, 삭제 범위 안내)** · 페이지 번호

### 회의록 뷰어 `/jobs/[id]` (`job-result.tsx`, `minutes-panel.tsx`)

- 일시·참석자(편집) / 복사 3종 / 원문 TXT·Markdown 받기
- 왼쪽 **Whisper 변환 원문**: 타임스탬프를 누르면 원본 음성을 그 위치부터 재생, ±5초·배속, 지금 문장 강조. 원본 음성은 처음 재생할 때 받아 옴
- 오른쪽 **AI 회의록**: 탭(구조화된 회의록 / 핵심 요약 / 할 일·Action Items — `## 제목` 구획을 골라 보여 줌), 편집·저장, 새로 만들기(확인 창)

### 말모아 달력 `/calendar` (`calendar-view.tsx`, 10/30 다시 정리)

- 도구 줄: ◀ 월 ▶ · 오늘 · **다음 일정 알림**(누르면 일정 창) · 일정 추가
- **월간 일정표** 구획: 요일 머리줄(회색 입체), 날짜는 Space Mono, 오늘은 남색 칸 + `TODAY`, 고른 날은 연보라 + 남색 테두리, 칸 안 일정 칩(회의 남색·기타 회색·자동 녹음 예정 빨간 점, 넘치면 `+n개 더`), 아래 범례. 좁은 화면은 칩 대신 점
- 오른쪽 **고른 날 일정** 구획: 시각(Space Mono)·종류 표시·제목·장소·참석자·알람·자동 녹음 상태·메모(노란 칸), 왼쪽 색 띠(회의 남색), ✕ 삭제, 연결된 녹음 보기, 아이폰 동기화 실패 다시 시도
- 상태 표시줄: 이 달 일정·회의·자동 녹음 예정 개수, 고른 날

### 시스템 설정 · 사용 안내 · 로그인

같은 창 틀에 넣음. 기능 변화 없음. 일정 창(`event-editor.tsx`)은 **위쪽에도 저장 단추**를 두고, 회의/기타·알람 선택이 눌린 모양으로 보이게 함(자동 녹음 체크박스가 "회의"일 때만 보이는데 선택 표시가 안 보여 "없어졌다"고 느낀 문제).

## 5. 시안과 다르게 한 것 (CLAUDE.md "실제 기능과 연결되지 않은 버튼은 만들지 않는다")

| 시안 | 처리 |
|---|---|
| TASK_ID, GPU·NPU 가동률, 디스크 여유 공간, 신뢰도 %, 한/영 표시, 스피커 아이콘 | 없음 (지어낸 숫자가 됨) |

| "화자 자동 분리" 안내 | "참석자 기록" — 말한 사람 구분은 하지 않음 |
| 작업 취소, 위로/아래로 이동, 단어 교정 창 | 없음 (해당 기능 없음) |
| 창 안 메뉴(효과(S) 등) | 실제로 갈 곳이 있는 메뉴만 둠 |
| 회의록 뷰어의 화자 이름 | 타임스탬프만 (화자 구분 없음) |

## 6. 검증 (실제로 한 것)

- 시험 환경: 백엔드 8003(`malmoa_test` DB, 스크래치 저장소) + 프런트 5182(복사본 개발 모드). **실제 앱 3001은 시험 브라우저로 열지 않음** (자동 녹음을 가로챈 10/29 사고 이후 규칙)
- 화면 캡처(1600·1280·390px)로 4개 화면·달력·설정·안내·좁은 화면 확인, 브라우저 오류 없음
- 단축키로 녹음 시작·일시정지·재개·종료·초기화, 12초 녹음 → 텍스트로 변환 → 진행 4단계 → 결과 문서 표시, 녹음기에서 m4a 업로드 → 변환 → 원문 표시
- `tsc --noEmit`, `eslint src`, 배포 빌드(`next build`, 복사본) 통과. 백엔드 테스트는 이 작업에서 바꾼 것이 없어 다시 돌리지 않음

**확인하지 못한 것**
- 파형·LED 레벨이 실제 말소리에 움직이는지: 시험 브라우저의 가짜 마이크는 소리 파일을 넣어도 무음이라 볼 수 없었음 → 사용자 Mac에서 확인 필요
- 긴 녹음에서 "음성 → 텍스트" % 가 올라가는 모습 (시험 녹음이 짧아 몇 초 만에 끝남)
